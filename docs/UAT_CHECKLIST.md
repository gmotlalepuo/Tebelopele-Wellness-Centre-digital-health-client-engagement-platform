# User acceptance checklist

Record tester, role, environment, date, evidence link and result for every case.

- Public service, facility, health-information, FAQ and privacy journeys.
- Client registration/sign-in, profile, consent, preferences, appointments and notifications.
- Chat answer provenance, uncertainty, crisis boundary, escalation and transcript handover.
- Support eligibility, claim, reply, private note, reassignment and resolution.
- Referral valid/invalid transitions, follow-up scheduling and closed-state protection.
- Report totals and CSV reconciliation within each role's access scope.
- Admin configuration and governed content workflow.
- Audit and provider failure visibility.
- Keyboard-only, screen reader, 200% zoom and mobile viewport operation.
- Slow/interrupted connection recovery and useful error/empty states.
- Backup restoration, rollback and incident-contact rehearsal.

Final sign-off requires named product, operations, privacy/security and technical owners, with all exceptions recorded and accepted.
